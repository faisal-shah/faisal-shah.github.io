What’s new in v0.8.0

Name a file before it uploads. Pick a file and you now get a box showing its name, size and kind. Change the name if you want — IMG_20260815_113244 means nothing to anyone next week — and press Upload. This is the only chance to name it; to fix a name afterwards, remove the file and attach it again.

Search sorts by last activity. A new Sort control offers newest first or oldest first, so you can see what has been happening lately, or what nobody has touched in months. Comments and attached files now count as activity, not just edits to the card itself.

Search’s filters were rearranged. Filters now holds priority (all five, and you can pick more than one — urgent or high), board, labels, and a new Assigned to. Board, labels and people each have a box you can type in to narrow a long list. Archived and Overdue stay as they were.

Stats: tap a bar. Managers and admins can now tap any bar in the chart to see what is behind it — which boards those numbers came from, largest first, with a tap through to the board; or, on Active people, who was actually active.

Get it from Google Play

Kanban is on Google Play, and that is where the team should install it from — updates then arrive on their own. The download further down this page is a test build, published before a release reaches Play; unless you have been asked to try one, use Play.

Do not install both. Android will not replace an app with a copy signed differently, so a download from this page cannot install over the Play version, or the other way round — it fails with only “App not installed” to explain why. Uninstall the one you have first. Nothing is lost: your boards, cards and comments are stored online, so signing in brings everything back.
