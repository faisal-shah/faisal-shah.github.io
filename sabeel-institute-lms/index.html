Sabeel Institute LMS

Sabeel Institute’s learning app: attendance, class recordings, assignments and grades. Teachers take the register, share recordings and set and grade work; students catch up on classes they missed and see what is due. Students sign in with the email their teacher registered; staff sign in with their Sabeel Google account and are approved by an administrator.

A pre-release, open to testers. This is the new home of Sabeel Class Recordings, and the institute's classes stay on that app until it announces the day everyone moves. Sign in with your usual account. Anything done here before that day is test data, and is cleared when everyone moves.

Version 0.2.0, a pre-release, October 2026. New: the institute's rules, agreed to once, and Report a problem in More, which goes to the administrators by email; password emails come from the institute's own address. In 0.1.2: a bookmark carries your place in a recording to another device. Assignments and grades came in 0.1.0. Read the user manual (PDF).

Install on Android

Current build: v0.2.0, published 16 October 2026. The download link stays the same when a new build is published, so this page is always the latest.

Download for Android (45 MB) For any phone from roughly 2016 onward. Start here. Download the all-devices build (103 MB) Only if the one above won't install — it's larger but runs anywhere.

Android will warn about installing outside the Play Store and ask you to allow it for your browser. That is expected for an app distributed directly like this.

There is no iPhone version yet; use the web app on an iPhone.
